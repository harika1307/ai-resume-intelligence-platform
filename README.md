# 🤖 AI Resume Intelligence Platform

An AI-powered Resume Intelligence Platform that analyzes resumes against job descriptions and provides an ATS score, skill analysis, and personalized AI feedback.

---

## ✨ Features

- 📄 Upload Resume (PDF)
- 📝 Paste Job Description
- 📊 ATS Score Calculation
- ✅ Matched Skills Detection
- ❌ Missing Skills Identification
- ⭐ Extra Skills Analysis
- 💡 AI-powered Resume Feedback
- 🔑 Keyword Suggestions
- 🎯 Learning Roadmap
- ❓ AI-generated Interview Questions

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/harika1307/ai-resume-intelligence-platform.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
